# BusiMatch

**One ID. One ecosystem for small businesses, creators and communities.**

BusiMatch is a family of connected platforms, built in Belgium.
You sign in once with your BusiMatch ID and use everything: a community, a design studio, free online tools, a website builder and an academy.

This profile is a showcase.
It explains what BusiMatch is and how the parts fit together.
The source code is not published here.

## The platforms

| Platform | What it is |
|---|---|
| [busimatch.com](https://busimatch.com) | The information site: what BusiMatch does, in 15 languages. |
| [busimatch.club](https://busimatch.club) | The community and the back office: your profile, your businesses, blog, chat and wallet. |
| [busimatch.tools](https://busimatch.tools) | More than 360 online tools and plugins, each one standalone. |
| [busimatch.studio](https://busimatch.studio) | Busi Studio: design personalised products such as business cards, flyers, posters and clothing. |
| [busimatch.online](https://busimatch.online) | Busi Online: build your own website without code. |
| [busimatch.academy](https://busimatch.academy) | BusiMatch Academy: learn, teach and grow. |
| [busiverse.network](https://busiverse.network) | The Busiverse: the overview of the whole ecosystem. |

## How it fits together

```
                 BusiMatch ID  (one sign-in for everything)
                        |
                 busimatch.club
          community, profile, back office
                        |
    +-----------+-------+-------+------------+
    |           |               |            |
  Studio      Tools          Online       Academy
  design      plugins        websites     courses
```

- **BusiMatch ID** is the single sign-in. Every platform trusts it, so you never create a second account.
- **busimatch.club** is the heart. From there you go to the Studio, the tools, your website and your courses.
- **busimatch.tools** is the home of the plugins. A plugin works on its own, and the Studio can load it when you need it.
- **Busi Studio** is where you design. Its modules cover vector drawing, documents, spreadsheets, presentations, photo, film, sound, 3D and more. See the [module overview](https://busimatch.studio/modules/).
- **Busi** is the rabbit mascot and the AI assistant that helps you inside the platforms.

## Principles

- **One identity.** One BusiMatch ID, no separate accounts per site.
- **15 languages.** English, Dutch, French, German, Spanish, Italian, Portuguese, Polish, Russian, Arabic, Romanian, Turkish, Japanese, Chinese and Hindi.
- **Your work stays yours.** Designs are saved in a `.busi` project file that you can download.
